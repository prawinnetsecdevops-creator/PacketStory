Features

Ranked executive summary

A 0-100 health score and issues ordered critical to low, each with a recommended action.

Every port and protocol

TCP, UDP, DNS (UDP and TCP), DHCP, ICMP/ICMPv6, ARP and other IP protocols.

TCP and MTU diagnostics

Handshake failures, resets, retransmissions, windows, RTT, MSS/MTU, fragmentation and PMTU black holes.

TLS insight

SNI, ALPN, TLS 1.3 detection, missing ServerHello and deprecated versions. Load an SSLKEYLOGFILE to decrypt certificates, alerts and DNS-over-TLS.

Many captures at once

Upload several files, compare them side by side, or merge them into one timeline.

Private by design

Runs on your computer. Your captures are never uploaded anywhere. Export findings to CSV.

Get started in 30 seconds

  1. Download PacketStory-Portable.zip.
  2. Extract it anywhere and run PacketStory\PacketStory.exe.
  3. Drop one or more capture files into the window.
Windows SmartScreen may warn because the app is not code-signed yet: choose More info → Run anyway. Prefer source? It is pure Python with no required dependencies: python app.py.
