PacketStory - Portable
======================
Every packet tells a story. Understand yours.

1. Extract the whole zip to any folder (a USB stick works too).
2. Run PacketStory.exe. No install and no Python needed.
3. Drop one or more .pcap / .pcapng files into the window.

Notes
- Needs Windows 10/11 with Microsoft Edge or Google Chrome (Edge is built in).
  Without them it opens your default browser instead; end it from Task Manager to stop it.
- Everything runs locally. Captures are never uploaded anywhere.
- Closing the window stops the program. Nothing is written outside a temporary folder that is deleted on exit.
- Windows SmartScreen or antivirus may warn about an unsigned app on first run: choose
  "More info" > "Run anyway".
